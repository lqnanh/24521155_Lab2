# Project Rules
- Ngôn ngữ: JavaScript ES modules (file mini-react.js), JSDoc để mô tả kiểu.
- Cấm: var, innerHTML, keyCode, inline handler (onclick=...).
- Bắt buộc: const/let, createTextNode/textContent, addEventListener.
- HTML đầu ra phải dùng thẻ ngữ nghĩa (main, header, section, button), cấm div-soup.
- Mỗi lần chỉ làm 1 hàm. Không viết thêm tính năng ngoài yêu cầu.
- Trả về: code + giải thích ngắn + các edge case đã xử lý.
